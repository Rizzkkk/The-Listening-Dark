# Changelog

## Deploying

The site is a git clone on the VPS, so deploying is a pull. There is no build
step on the server — `tools/build.py` runs locally and its output (the HTML) is
committed.

**From this machine, push and deploy in one line:**

```bash
git push && ssh USER@191.215.37.101 'sudo git -C /var/www/kpcapitulo pull && sudo chown -R www-data:www-data /var/www/kpcapitulo && sudo systemctl reload nginx'
```

- **`reload`, never `restart`.** This box hosts other sites; a restart drops
  every one of them for a moment, a reload drops nothing.
- The reload is only needed after an **nginx config** change. Content changes
  are live the moment the pull finishes — the HTML is served `no-cache`, so
  returning visitors get it immediately.
- If git refuses with "detected dubious ownership", run this once on the VPS:
  `sudo git config --global --add safe.directory /var/www/kpcapitulo`
- Verify what is actually live, rather than assuming the pull landed:
  `curl -sI https://kpcapitulo.com | head -3`
